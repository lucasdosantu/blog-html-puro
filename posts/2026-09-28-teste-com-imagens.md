O desenvolvimento de sites estáticos voltou a ganhar uma enorme popularidade devido à sua **velocidade**, **segurança** e **baixo custo de hospedagem**.

## Por que utilizar Markdown?

O Markdown permite focar na escrita do conteúdo sem se preocupar com a complexidade das tags HTML. Algumas das suas principais vantagens incluem:

1. **Sintaxe simples e legível** mesmo em texto puro.
2. **Portabilidade:** Podes mover os teus ficheiros para qualquer plataforma facilmente.
3. **Integração fácil** com bibliotecas de renderização como o [Marked.js](https://marked.js.org/).

## Links Úteis para Estudo

Para aprofundar os teus conhecimentos em tecnologias web puras, consulta estes recursos externos:

* [Documentação MDN Web Docs](https://developer.mozilla.org) — O melhor guia sobre HTML, CSS e JavaScript.
* [Guias Oficiais do GitHub Pages](https://pages.github.com) — Informação detalhada sobre como hospedar o teu projeto.
* [Unsplash](https://unsplash.com) — Banco de imagens gratuitas de alta qualidade para utilizar nos teus posts.

> **Dica:** Ao adicionar imagens no teu blog, garante sempre que utilizas URLs diretos (que terminam em `.jpg`, `.png` ou `.webp`) para que o navegador consiga exibi-las corretamente.
